# My Wall

Self contained app for managing your home climbing wall. Everything lives in a single HTML file, so it works anywhere, offline, is shareable, and can be printed to PDF.

## Features

- Single HTML file you can give to anyone. It saves to itself and can be opened in any browser, even offline.
- Add, edit, and delete routes
- Print a simple guidebook to PDF
